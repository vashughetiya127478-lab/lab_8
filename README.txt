DN-8 Inventory Management (ASP.NET Core MVC + ADO.NET SQLite)

Open DN-8.sln in Visual Studio 2022.
Use a .NET 8 SDK installation. Allow NuGet package restore (Microsoft.Data.Sqlite).
Set DN-8 as the startup project and press F5 or Ctrl+F5.

The app initializes inventory.db automatically in the application output folder and seeds three rows if the table is empty.
CRUD functions: Create/Add, List, Details, Edit/Update, Delete with confirmation.
